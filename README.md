# Summary

UD Middle Persian MPCD is a product of the Zoroastrian Middle Persian Corpus and Dictionary Project (https://www.mpcorpus.org/), which attempts to digitise all Zoroastrian Middle Persian texts. It includes the development of a dictionary and corpus with a user interface for annotation and queries.<br>The MPCD is a collaborative project of the Universities of Berlin, Bochum, and Cologne in Germany.

<br>For a detailed description see the handbooks:
- on morphology: https://gitlab.cceh.uni-koeln.de/mpcd/handbooks/-/wikis/Handbook%20Morphology
- on syntax: https://gitlab.cceh.uni-koeln.de/mpcd/handbooks/-/wikis/Handbook%20Syntax

# Introduction

The Zoroastrian texts are checked against original manuscripts, and transliterated and transcribed manually. Annotators add a semantic and morphosyntacic annotation following the UD standard.<br>
It consists of various text types including theological treatises, encyclopediae, legal texts, wisdom literature, translations of Avestan, the holy language of the Zoroastrians, and colophons. The table below lists text sigla found in the sentence ID together with a short description.


Each text received a full semantic and morphological annotation, and at least 10% syntactic annotation.<br>
Some texts are attested in more than one manuscript, which are treated as independent texts sharing the same abbreviation but differ in the manuscript (e.g. Greater Bundahišn: GBd and GBd-TD1: Greater Bundahišn according to the manuscript TD1 vs. GBd-DH: Greater Bundahišn according to the manuscript DH).


As of 5 February 2026, the MPCD corpus includes 40,233 sentences in altogether 47 texts.<br>
5,012 sentences have been fully annotated in altogether 23 texts, which comprise together 33,866 sentence.
